# LinkX 网页管理后台

一个静态网站、一套管理界面，管理接口统一使用腾讯云服务器上的业务后端。源码不包含数据库、云函数或另一套登录系统。

- 网站：`https://admin.linkx.ink/`。
- 管理入口：`https://admin.linkx.ink/admin/`。
- API：`https://collect.linkx.ink/api/v1/admin/*`；域名配置位于 `admin/public/admin-config.js`，不含密码和密钥。
- 业务后端：相邻仓库 `../wx/services/backend`，PostgreSQL 是唯一业务数据库。

## 目录

```text
site/                 网站首页、路线参考价格与微信小程序引导
admin/src/            管理界面与固定 API 调用
admin/src/catalog.js  数据表与字段的中文说明
admin/tests/          权限、保存恢复、轮询和后端联调测试
public/               网站图片、主题脚本和图片授权
scripts/              静态预渲染与管理界面打包
```

已移除旧 Next/Vinext、Sites、D1、Cloudflare Worker 和 CloudBase 管理传输。没有自动切回旧数据库的路径。旧浏览器里的待确认批次不会自动转换成新请求或被清空。

## 运行与发布

Node.js 24 推荐；最低 22.13。

```sh
npm ci
npm --prefix admin ci
npm run dev
npm --prefix admin run dev
npm run build
npm run check
npm test
```

`dist/` 是唯一发布产物，包含首页和独立的 `dist/admin/index.html`。生产用 Caddy 提供静态文件；不在服务器运行 Vite 开发服务。上传到新的版本目录，核验后切换静态目录，避免 HTML 引用尚未上传的脚本。

管理配置采用带内容摘要的文件名。API 地址变化时，重新构建、先发布资源、最后切换 HTML。不要只覆盖一个长缓存配置文件。站点新 origin 必须同时加入后端 `admin_origins`；CORS 不使用通配符。

## 两级管理员

普通管理员保留原账号，管理批量发布、社区内容批量删除、文字模板、群二维码和公告。每次最多发布或删除 50 条，删除为软删除，原记录保留。

最高管理员 `superadmin` 另有运行监控、数据库浏览和采集记录。权限由服务端每次校验；普通管理员不会加载控制台数据。最高管理员可以编辑其他用户的商品文字和上下架状态，保持原图片引用与到期时间。

数据库按表分页，并支持精确记录 ID、OpenID 或关联用户 ID 查询。完整记录保留字段名、中文含义和类型说明。第一期直接编辑仅开放用户显示名称和个人资料；商品、群码与公告使用各自管理功能。关系、行程成员、回执、迁移归档等只读，密码、会话凭证和密钥不展示。没有任意 SQL 终端。

## 运行监控与数据查看

最高管理员登录默认打开运行监控，显示调用频率、活跃账号、采集事件、CPU 与服务状态。可查看最近 1 天、7 天、30 天历史：按 2、15、60 分钟分桶，显示有效记录的均线与真实峰谷范围，并标明峰值时刻；计数轴根据峰值调整，CPU 固定 0–100%。新统计启用前没有记录，缺失或不完整分钟留空，不补 0。仅监控页可见且浏览器前台时，实时状态每 10 秒刷新，历史独立每 60 秒刷新；请求不重叠，失败保留上次数据并说明状态。服务端也缓存采样，不持续全库扫描。

接口请求分为直连、转接与采集，每次批量上传计一次请求；采集事件按去重后的记录计数。活跃账号是接收采集事件的每分钟唯一真实账号，不是在线人数或全平台注册数，不跨分钟累加。

采集按服务器接收时间从新到旧分页。可用 OpenID、用户 ID 和接收时间段筛选；客户端事件发生时间另列，避免把设备时钟当成服务器时间。事件类型只筛选当前页。最近一分钟的数量触及扫描上限时显示“至少”，不伪造全库总数。数据浏览和采集列表按需刷新，不持续轮询。

## 保存与恢复

提交前在浏览器保存原操作编号、版本和请求内容。网络中断或结果未知时，只能重试原内容或点击“核对上次保存结果”；不会隐式重试或以新编号重复写入。修改带版本检查，避免覆盖他人更新。

批量发布草稿按后端地址和账号隔离。刷新前保存的是文件 ID，不保存临时签名 URL；图片链接每五分钟刷新。更换账号不会继续发送上一账号的草稿。浏览器持久存储不可用时阻止新写入。

## 账户与测试

密码使用服务端 scrypt 摘要，会话随机令牌仅放 `sessionStorage`；服务端保存哈希。密码交付文件与服务器密钥不进 Git、静态目录或构建产物。停用账号、修改密码或权限会撤销原会话。

真实后端联调用 Node.js 24、隔离的本地 PostgreSQL schema 和合成资料：

```sh
BACKEND_SOURCE_DIR=/absolute/path/to/wx/services/backend \
BACKEND_TEST_DATABASE_URL=postgresql://localhost/test_database \
npm --prefix admin test
```

没有上述变量时，后端联调明确标记跳过。测试不访问生产数据库、CloudBase 或对象存储。发布前另外核验生产登录、两级权限、CORS/CSP、监控与真实数据读取。
